📊 Data Analytics Project
🧠 Overview

This project demonstrates a complete end-to-end data analytics workflow — from importing and cleaning data to generating insights through SQL and creating an interactive Power BI dashboard. The goal is to simulate real-world analytics processes and show how raw data can be transformed into valuable business insights.

🗂️ Dataset

The dataset contains information about customer transactions and purchasing behavior.
It includes columns such as Customer ID, Age, Gender, Product Category, Purchase Amount, Region, and Frequency.
The data is used to identify patterns, trends, and actionable insights to improve business decisions.

🧰 Tools & Technologies Used
Tool / Language	Purpose
Python (Pandas, NumPy, Matplotlib, Seaborn)	Data loading, cleaning, and exploratory data analysis (EDA)
SQL (MySQL / PostgreSQL / SQL Server)	Querying data and extracting business insights
Power BI	Creating dashboards and data visualizations
Gamma AI / PowerPoint	Building a professional project presentation
Jupyter Notebook / VS Code	Writing and executing Python scripts
⚙️ Steps Followed
1️⃣ Load the Dataset

Import the dataset into Python using Pandas.

Explore its structure, column details, and data types.

2️⃣ Data Cleaning

Handle missing values and duplicates.

Standardize column names and formats.

Treat outliers and convert data into usable formats.

3️⃣ Exploratory Data Analysis (EDA)

Analyze customer behavior and trends.

Generate summary statistics and visualizations using Matplotlib and Seaborn.

Identify key patterns such as top products, regions, and customer segments.

4️⃣ Data Analysis Using SQL

Export cleaned data from Python to an SQL database (MySQL/PostgreSQL/SQL Server).

Write and execute SQL queries to answer business-related questions such as:

Which product category generates the most revenue?

Who are the top customers by total spend?

Which regions show the highest customer engagement?

5️⃣ Dashboard Creation

Connect the SQL database to Power BI.

Design an interactive dashboard displaying KPIs such as sales, customer segments, and revenue by region.

Add filters, slicers, and charts to visualize the data dynamically.

6️⃣ Reporting & Presentation

Summarize findings and recommendations in a report.

Create a professional presentation deck using Gamma AI or PowerPoint to visually communicate insights.

📊 Dashboard Overview

The Power BI dashboard includes:

Total sales and revenue performance

Top products and categories

Customer demographics and purchase behavior

Regional insights and trends

These visuals help stakeholders quickly understand business performance and identify areas for growth.

🧩 Results & Insights

Customers aged 25–35 contribute most to total revenue.

Electronics and fashion are top-performing categories.

Region A shows the highest customer retention.

Loyal customers drive over 60% of repeat purchases.

🚀 How to Run the Project

1️⃣ Clone the repository

git clone https://github.com/Hemanthkumar-Mekala/Customer_behavior_analysis.git
cd Customer_behavior_analysis

Customer_Shopping_Behavior_Analysis.ipynb

5️⃣ Execute queries in customer_behavior_sql_queries.sql.
